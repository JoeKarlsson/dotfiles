# OpenCode-only rules

Claude Code gets these from its mods and hooks. OpenCode has no such hooks, so they're written here.

- Commit messages: `feat: <Summary>`, `fix: <Summary>`, or `chore: <Summary>` (chore for changes that aren't user facing). The summary starts with an uppercase letter.
- Never use an em dash. Use a comma, colon, or a new sentence.
