# Design library

`palettes.json` (64 palettes) and `type.json` (38 Google Fonts pairings) come from taste-skill 2.5.1, https://github.com/Leonxlnx/taste-skill, MIT License, Copyright (c) 2026 Leonxlnx. Each palette's `note` says how the colors are spent on a page.

How to use them: `../web-design-no-ai-slop.md`, "First: the goal, then the direction, then the style". Ignore `tracking` values and the Instrument Serif pairing (both banned there).

`board.py <this folder> <out.html>` renders every palette and pairing as a numbered board. Cut palettes Joe rejects from `palettes.json` and note it in the rule.
